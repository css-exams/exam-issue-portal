# بوابة الإبلاغ عن إشكالات أسئلة الاختبارات – النسخة المصممة

## الملفات
- `index.html`: صفحة مكتملة التصميم **ومستقلة ذاتيًا**. تحتوي على CSS وJavaScript وشعار الكلية وقائمة المقررات الـ173 كاملة، دون تحديد عدد نتائج البحث داخل الملف نفسه؛ لا تحتاج إلى رفع أي ملفات خارجية لعرضها. خط Cairo يتحمل من Google Fonts إن توفر الاتصال، وإلا تستعمل الصفحة خطوطًا بديلة.
- `google-apps-script/Code.gs` و`Courses.gs`: خدمة اختيارية لإرسال البلاغات إلى Google Sheets وحفظ الصور/ملفات PDF في Google Drive **عند تفعيلها لاحقًا**.

## نشر الصفحة على GitHub Pages
1. افتح GitHub وأنشئ مستودعًا عامًا جديدًا، مثل `exam-issue-portal`.
2. ارفع الملف `index.html` إلى **جذر المستودع** (يمكن رفع `README.md` ومجلد `google-apps-script` أيضًا، لكن لا يلزمان لعرض الصفحة).
3. افتح `Settings → Pages`، ثم `Build and deployment: Deploy from a branch` واختر `main` و`/(root)`، ثم Save.
4. افتح رابط GitHub Pages الذي يظهر في إعدادات Pages، ويمكن وضع الرابط بعد ذلك في بوابة الطالب دون ربط تقني.

## مهم: هل يعمل إرسال البلاغات الآن؟
لا. الواجهة الآن مخصصة للمعاينة فقط، وتعرض تنبيهًا بذلك، ولن تدعي حفظ البلاغ قبل تفعيل خدمة الاستقبال. نشر HTML وحده لا يحفظ الردود أو الملفات.

## الربط لاحقًا بحساب Google مستقل (لا يلزم حساب الكلية)
1. أنشئ Google Sheet ومجلد Google Drive خاصًا من الحساب الذي تريده.
2. افتح Google Apps Script وأنشئ مشروعًا، وانسخ محتويات `google-apps-script/Code.gs` إلى Code.gs و`google-apps-script/Courses.gs` إلى Courses.gs.
3. أضف في `Script properties` الخاصيتين `SHEET_ID` و`FOLDER_ID` بالمعرّفين الصحيحين.
4. شغّل `initialize` مرة واحدة، ثم انشر Web app بصلاحيات مناسبة. النموذج العام دون تسجيل دخول يتطلب وصول `Anyone` وتشغيل `Execute as me`، وهو إعداد يجب تقييم مخاطره قبل استقبال بيانات حقيقية.
5. افتح `index.html` في محرر نصوص، وابحث عن:
   `endpoint: '',`
   ثم استبدلها مثلًا بـ `endpoint: 'https://script.google.com/macros/s/....../exec',`
   واحفظ وارفع النسخة المعدلة إلى GitHub. **لا تضع كلمات مرور أو مفاتيح سرية داخل HTML**.
6. اختبر إرسال بلاغ غير حقيقي، ولا تعتمد النشر قبل التحقق من وجود الصف في Sheets والملف في Drive وظهور الرقم المرجعي.

## اعتبارات الخصوصية والأمن
- الواجهة تستضيفها GitHub Pages علنًا، لكن البيانات لا تحفظ على GitHub.
- إذا نشر Apps Script بصلاحيات المالك للجميع، فواجهة الاستقبال عامة ويمكن إساءة استخدامها؛ تحقّق من قيود الاستخدام، والحماية من البلاغات الآلية، وحصص Google، وصلاحيات المجلد الخاص، وموافقة مسؤول البيانات قبل استقبال بيانات فعلية.
- المرفقات الاختيارية محددة بـPDF/JPG/PNG/WebP وحجم 2 ميجابايت. لا تُشارك مجلد المرفقات للعامة.
- يوجد **173 مدخلًا للمقررات كما أرسلها المستخدم**، وبعض الرموز مكررة بين مسميات مختلفة؛ يجب التأكد من الرموز قبل التشغيل المؤسسي.

## تحديث الحقول (نوفمبر 2026)
- تمت إضافة رقم الهاتف (اختياري)، مع حفظه في جدول Google Sheets عند تفعيل الخدمة.
- أنواع السؤال: صواب وخطأ، اختيار من متعدد، مقالي، أخرى.
- قائمة المقررات تتضمن **173 مقررًا**؛ تظهر جميعها في البحث ويمكن تمرير النتائج، مع عداد بعدد النتائج.
- **مهم عند وجود جدول سابق**: إذا كان قد تم تفعيل خدمة استقبال بلاغات باستخدام النسخة القديمة، يلزم تحديث عمود رقم الهاتف في Google Sheets ومراجعة ترتيب الأعمدة؛ لا تكتفِ باستبدال السكربت دون ترحيل البيانات.
- لا يعمل إرسال البلاغات قبل إعداد خدمة Google Apps Script المستقلة.
